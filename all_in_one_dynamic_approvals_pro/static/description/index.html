All In One Dynamic Approvals

Overview

You can create desirable approvals without any customizations. The app can create approval dynamically. It supports all modules contains the Header, State fields with Selection Type, Company field and Context. The application can be support in Odoo Community and Enterprise versions. The new features will be freely available on the app update. The approval does not affect old records, Instead it will be applicable only for newly created records.

Features

  • Support Multi Approvers in sequence wise and parallel.
  • Support Multi States.
  • Support Multi Company.
  • Rejected Record Resend Option.
  • Approvers Updating Option.
  • Email Notifications for Approver and Requester.
  • Status Adding in Tree view .
  • Disable Report Print Button.
  • Approval History In Chatter.
  • New Hierarchical Approval.
  • Added new User group Manager.
  • New Stage/stage_id specific Approval.
  • Tracking for field Approval id with extra security.
  • Added Approval type with normal, employee manager and custom type of approval.
  • Email notification on creation and cancellation of approval to Authority.
  • Approval for CRM generated Quotations.
